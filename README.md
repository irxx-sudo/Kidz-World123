# KidzWorld – Kalvium Assignment

This repository contains the **KidzWorld** website, a front-end web project developed as part of an assignment given by **Kalvium**.

🔗 Live Website: https://irxx-sudo.github.io/KidzWorld-Kalvium/

## About the Project

KidzWorld is a simple and visually structured website designed to represent an online kids store. It features different sections such as books, games, and handmade items, focusing on clean layout and user-friendly design.

The project was built to practice and strengthen front-end development fundamentals using HTML, CSS, and JavaScript, following the guidelines provided by Kalvium.

## Features

- Clean and simple UI design  
- Product sections with cards  
- Basic interactivity using JavaScript  
- Organized file structure  
- Deployed using GitHub Pages  

## Technologies Used

- HTML5  
- CSS3  
- JavaScript  

## Purpose

This project was created purely for **learning and practice** as part of Kalvium’s web development curriculum.
